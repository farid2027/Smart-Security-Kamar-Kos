# Smart-Security-Kamar-Kos
Smart Security Kamar Kos adalah program komputer berupa dashboard web yang berfungsi sebagai sistem keamanan dan kenyamanan kamar kos berbasis Internet of Things. Sistem ini dirancang untuk bekerja bersama mikrokontroler ESP32, sensor PIR untuk mendeteksi gerakan, sensor suhu LM35, relay dengan kipas DC, dan buzzer sebagai alarm.
